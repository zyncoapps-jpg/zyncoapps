PUBLISH ON GITHUB PAGES
1. Create or open the public repository:
   https://github.com/zyncoapps-jpg/zyncoapps

2. Upload the contents of this folder to the repository root.

3. In GitHub open:
   Settings > Pages

4. Choose:
   Source: Deploy from a branch
   Branch: main
   Folder: / (root)

5. Save.

Expected public URL:
https://zyncoapps-jpg.github.io/zyncoapps/

IMPORTANT PRIVACY CHECK
The privacy policies describe offline, no-account versions of the apps.
Before publishing them as final Google Play policies, confirm that the release
builds do not use analytics, advertising, account systems, cloud sync, crash
reporting, or other data handling that is not mentioned in the relevant policy.
